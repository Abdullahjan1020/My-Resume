# My Resume

This project is a simple responsive resume webpage created for a Web Engineering lab task.

## Purpose

The page presents Abdullah Jan's profile, education, skills, projects, and contact links using semantic HTML and CSS. It demonstrates:

- Structuring content with HTML5 sections
- Styling a readable resume layout with CSS
- Using Flexbox for the skills list
- Applying media queries for tablet and mobile layouts

## Files

- `AbdullahJan527940.html` - The resume page structure and content
- `AbdullahJan527940.css` - The page styling and responsive design rules

## How to Run

Open `AbdullahJan527940.html` in any modern web browser
